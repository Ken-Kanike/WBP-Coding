1. PHP Data Types & Output Functions

PHP is dynamically typed with strict typing capabilities. Core primitive types include int, float, string, bool, array, and null.

<?php
$int = 42;
$float = 99.95;
$string = "Web Programming";
$bool = true;

// Formatted print
printf("Integer: %d | Float: %.2f | String: %s", $int, $float, $string);

// Constants
define("APP_VERSION", "2.0.0");
const SITE_NAME = "WBP Mastery";
?>

    case 'Sunday':    echo "Weekend mode active!"; break;
