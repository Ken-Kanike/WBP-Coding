## 🌟 Overview & Key Features

## ⚡ Quickstart Guide

### Option 1: Live Interactive Browser (No Setup Required)
Browse all interactive forms and code samples directly on GitHub Pages:
👉 **[https://ken-kanike.github.io/WBP-Coding/](https://ken-kanike.github.io/WBP-Coding/)**

---

### Option 2: Local Server Execution (PHP + Apache / XAMPP)

1. **Clone the Repository:**
   ```bash
   git clone https://github.com/Ken-Kanike/WBP-Coding.git
   cd WBP-Coding
   ```

2. **Run via PHP Built-in Server:**
   ```bash
   php -S localhost:8000
   ```
   Open [http://localhost:8000](http://localhost:8000) in your web browser.

3. **Run via XAMPP / WAMP:**
   - Copy or symlink the repository into your webroot (`C:/xampp/htdocs/WBP-Coding` or `/var/www/html/WBP-Coding`).
   - Start **Apache** and **MySQL** from the XAMPP Control Panel.
   - Access the portal at [http://localhost/WBP-Coding/](http://localhost/WBP-Coding/).

### 📚 PHP Textbook Chapter Modules

The [`PHP_Book/`](PHP_Book/) directory contains detailed conceptual modules:

- **[Chapter 1: PHP Basics & Control Structures](PHP_Book/chapter1.php)**: Data types, operator taxonomy, date functions, matrix tables, and mathematical sequences.
- **[Chapter 2: Array Operations & Built-ins](PHP_Book/chapter2.php)**: Associative arrays, `extract()`, `compact()`, `explode()`, `implode()`, and array pointers.
- **[Chapter 3: Object-Oriented PHP](PHP_Book/chapter3.php)**: Classes, constructors, method overrides, and data encapsulation.
- **[Chapter 4: Advanced Web Programming](PHP_Book/chapter4.php)**: GD graphic rendering, file handling, session lifecycle, and IMAP processing.
- **[Chapter 5: Database Engineering](PHP_Book/chapter5.php)**: Comprehensive MySQLi reference guide, database schema scripts, and CRUD query syntax.
- **[Demo Form Handler](PHP_Book/demoHTML.html)** &bull; **[Live Form Demo](https://ken-kanike.github.io/WBP-Coding/PHP_Book/demoHTML.html)**: Interactive demonstration of POST parameter dispatch to [`demoServer.php`](PHP_Book/demoServer.php).

## 🛠️ Tech Stack & Architecture

- **Backend Logic**: PHP 8.x / 7.4 (Vanilla, MySQLi, GD Library, IMAP, FPDF 1.84)
- **Database**: MySQL / MariaDB
- **Frontend**: Semantic HTML5, Vanilla Modern CSS3 (Glassmorphism, Flexbox, CSS Grid), Vanilla JavaScript (ES6+)
- **Typography & Icons**: Google Fonts (*Outfit*, *Plus Jakarta Sans*, *JetBrains Mono*), FontAwesome 6.5
- **CI/CD & Hosting**: GitHub Actions, GitHub Pages static artifact deployment

## 🔒 Security & Privacy Sanitization

This repository has undergone an exhaustive production audit:
- All sensitive personal names and email addresses have been sanitized to developer placeholders (`developer@example.com`, `Alex`, `Sarah`, `Ethan`).
- Hardcoded local file system paths (`C:/...`) have been replaced with portable dynamic PHP path constants (`__DIR__`).
- Clean repository exclusion policies enforced via [`.gitignore`](.gitignore).
